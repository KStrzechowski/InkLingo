## AI Toolkit — code-review skill

This repo has the `code-review` Agent Skill installed (`.claude/skills/code-review/SKILL.md`, from `@kstrzechowski/ai-toolkit`). Invoke it for review requests: "review code", "check this PR", "review my changes", "code review". It checks changes against six categories — Naming, Error Handling, TypeScript, Function Design, Security, Testing — and closes with one of `APPROVE` / `REQUEST CHANGES` / `NEEDS DISCUSSION`.
